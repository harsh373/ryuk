# Changelog

## [0.1.0] - unreleased

First public version. Early, and only tested on Fedora 43 / GNOME Shell 49.1 / Wayland.

- Autonomous slow movement: walk, stand, look around, sit, dangle, draw, phone, sleep
- Climbing walls and ceiling, hops and jumps (each can be turned off)
- Drag and drop with falling and landing
- Apple feeding from the panel menu
- Optional visibility over fullscreen windows (off by default)
- Panel menu and preferences window: speed, behaviour frequency, size, pause, hide
- Settings persist; no autostart unless "Keep running across logins" is on
- Release zip installable with `gnome-extensions install`, sprites bundled
